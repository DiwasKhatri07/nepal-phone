# Contributing to Nepal Phone

Thank you for helping improve Nepal Phone.

## Before you start

Please search existing issues before opening a new one. For bugs, include the input, expected result, actual result, Node.js version, and a minimal reproduction.

## Local workflow

```bash
git clone https://github.com/DiwasKhatri07/nepal-phone.git
cd nepal-phone
npm install
npm test
```

Create a focused branch, make the smallest clear change, add tests, and update the README when the public API changes. Use clear commit messages and explain the motivation in your pull request.

## Pull requests

A pull request should:

1. Explain the problem and the chosen solution.
2. Include tests for new behavior or regressions.
3. Keep unrelated formatting and refactors out of scope.
4. Pass the existing test suite.
